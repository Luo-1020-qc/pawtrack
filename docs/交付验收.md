## 浏览器验收操作

1. 在 390px 和桌面宽度下检查导航、卡片、弹窗无横向溢出。
2. 添加第三只宠物，切换宠物确认记录与时间线隔离。
3. 录入新体重，确认图表与时间线更新；刷新确认保留。
4. 添加疫苗/驱虫及下次日期，确认提醒；输入早于记录日的下次日期应报错。
5. 发布含照片动态，确认首页置顶、时间线联动、刷新保留。
6. 点赞再取消，确认数量恢复；切换同城筛选。
7. 筛选城市、地区和物种，确认结果及空状态；关注后刷新保留。
8. 更新昵称/城市，发布新动态确认使用新资料；导出 JSON。
9. 取消重置应保留数据；确认重置恢复两个宠物及六条演示动态。
10. GitHub Pages 部署后，用未登录窗口打开同一链接，并刷新 `#/records` 确认不出现 404。
